# AetherEngine

A lightweight, modular game engine in C++23 on Vulkan, by
[AIperture Labs](https://github.com/AIperture-Labs).

> Restarted from scratch in November 2026. The previous code base is archived
> in [AetherEngine-legacy](https://github.com/AIperture-Labs/AetherEngine-legacy).

## Status

Nothing to build yet. The roadmap is on the
[organization profile](https://github.com/AIperture-Labs); work is tracked in
[issues](https://github.com/AIperture-Labs/AetherEngine/issues).

## Stack

C++23 · Vulkan · CMake + Ninja · Python (editor automation) · Lua (game
scripting)

## Contributing

Issues and pull requests are welcome. Pull requests target the `dev` branch.
